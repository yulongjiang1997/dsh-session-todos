# 会话待办（@local/dsh-session-todos）

在**当前对话框**里预存要发给 Agent 的指令，之后点一下就能发送到当前会话，不需要新建会话，也不占左侧栏。

## 使用

### 打开待办弹窗

当前会话的输入框工具条左侧有一个「待办」按钮（清单图标，带未发送数量角标）。点击后，在输入框上方弹出**当前工作区**的待办列表：

- **发送**：把这条待办作为消息直接发送到**当前会话**（会话正在运行时进入队列）。
- **再发**：已发送过的待办仍保留，可以再次发送。
- **编辑 / 删除**：就地修改或删除；删除有二次确认。
- **清除已发送**：清掉当前工作区的发送记录。

### 预存一次会话数据

弹窗顶部：

- **存为待办**：把当前输入框里的草稿带入新建表单（连同当前工作区和 Agent 预设），确认后保存。
- **新建空白**：从空表单开始写一条待办。
- 表单里还有「带入当前草稿」，可以随时把输入框内容拉进来。

待办按工作区归属：同一个工作区的会话共享这份清单，切换会话后弹窗自动显示该工作区的待办。

## 持久化

待办跨重启保留。DSH 的 Web 界面每次启动可能使用不同的本地端口，页面 `localStorage` 会变成新的空存储，所以：

- 权威副本写在 `$DSH_HOME/dsh-session-todos.json`；
- Host 半边通过同源接口 `GET/POST /__dsh-session-todos/todos` 与页面同步；
- 页面里的 `dsh.session.todos.v1` 只是同源缓存。

## 实现说明

- `client.js`：输入框书签按钮、锚定弹窗、待办表单与列表，以及向当前会话发送（优先走 Client `Session.prompt`，保留本地回显）。
- `index.js`：Host 半边，注册同源读写接口并落盘到 `$DSH_HOME`。
- `cordis.patch.yml`：插入插件行。
- `locale/*.json`、`icon.svg`：插件管理中的标题、说明与图标。
- `test/host.test.cjs`、`test/client.test.cjs`：无浏览器环境下的 Host 持久化、纯函数与 Slot 注册冒烟测试。

## 已知限制

- 待办只保存文字指令（最多 20000 字）与可选的 Agent 预设；暂不保存附件、图片或模型选择。
- 发送目标始终是打开弹窗时所在的当前会话；如果会话处于归档或不可写状态，发送会内联报错。
- 待办列表的跨标签页同步依赖 Host 刷新，不做实时广播。
